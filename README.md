# CategorAIze — prototype

Public hosting for the **CategorAIze** design prototype, so testers have a permanent link.

**▶ Open the prototype:** https://akrueger47.github.io/categoraize-prototype/

Best viewed in Safari on an iPhone (it's built to feel like the real app). Tap the **≡** button in the
bottom corner to jump to any screen.

## Notes for testers

- This is an early **design prototype** — a clickable mock-up, not the finished app. Everything on screen
  is **sample data**; nothing you tap connects to a real account, budget, or inbox.
- It's a single self-contained page, so it also works offline once loaded, and you can **Add to Home Screen**
  to open it full-screen like an app.

## About this repo

`index.html` is a generated standalone build of the prototype. It's regenerated and re-pushed whenever the
design changes, so this page stays current.
